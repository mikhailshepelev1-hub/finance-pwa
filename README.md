# Финансы: личные и бизнес

Работает офлайн (данные в IndexedDB), синхронизируется через Supabase после входа.

## Публикация на GitHub Pages
1. config.js: URL проекта уже указан. Вставьте publishable key (Supabase -> Settings -> API Keys, формат sb_publishable_...) в поле key. Если у вас уже есть свой config.js с ключом, не заменяйте его файлом из архива.
   Секретный ключ (secret / service_role) вставлять нельзя.
2. На github.com создайте репозиторий (публичный). Add file -> Upload files: загрузите index.html, sw.js, supabase.js, config.js, manifest.webmanifest, icon-192.png, icon-512.png. Папку tests и README.md загружать не обязательно. Нажмите Commit.
3. Settings -> Pages -> Source: Deploy from a branch, Branch: main, папка / (root), Save. Через 1-2 минуты сайт откроется по адресу https://ЛОГИН.github.io/РЕПОЗИТОРИЙ/ (HTTPS).
4. Supabase -> Authentication -> URL Configuration: Site URL и Redirect URLs = этот адрес (со слэшем в конце).
5. Android: откройте адрес в Chrome -> меню -> Установить приложение. При обновлении файлов закройте приложение полностью и откройте снова.
6. Настройки -> Аккаунт: Регистрация, подтвердите e-mail по ссылке, вернитесь в приложение, Войти.
7. «Проверить синхронизацию»: статус должен стать зелёным.
8. После создания своего аккаунта отключите регистрацию новых пользователей в Supabase.

## Обязательная проверка на реальном облаке
- Тест синхронизации зелёный; в таблице нет строк с id, начинающимся на _probe.
- Операция на устройстве 1 появляется на устройстве 2 после «Синхронизировать»; удаление тоже.
- Второй аккаунт не видит записей первого.
- Режим самолёта: операция сохраняется, после возврата сети отправляется.
- Выход и повторный вход: данные на месте.
